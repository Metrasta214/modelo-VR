# Visor 3D VR con Three.js

Proyecto web para visualizar un modelo 3D exportado desde SketchUp en formato `.glb`, usando Three.js, Bootstrap y modo VR tipo Cardboard V2 para smartphone.

## Características

- Visualización de modelos 3D `.glb`
- Compatible con smartphone
- Modo VR tipo Cardboard V2
- Uso de giroscopio del teléfono
- Movimiento dentro del entorno 3D
- Soporte para control Bluetooth
- Puntos de referencia tipo marcador
- Teletransporte al mirar un punto
- Pantalla completa en modo VR
- Navbar y footer con datos del programador

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Bootstrap
- Three.js
- GLTFLoader
- StereoEffect
